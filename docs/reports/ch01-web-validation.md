# 聊天页面验收

日期：2026-10-19，Asia/Shanghai。

## 实现

入口 http://127.0.0.1:8000/，同一 FastAPI 服务通过 FileResponse 返回 app/web/index.html。
无新增前端依赖、无浏览器密钥。用户明确指定此页面采用 Vibe Coding，因此未套 brainstorm、TDD 或 code review；采用实际浏览器操作、截图核对和已有后端回归验证。

包含消息气泡、实时 SSE 解码与逐字排版、同会话连续追问、Enter 发送、Shift + Enter 换行、新对话、停止、过期/错误提示和响应式布局。

## 真实浏览器 + DeepSeek

浏览器 Microsoft Edge，真实模型 deepseek-flash。

1. 页面填写“我的订单号是WEB20261019001，收到的杯子破损，想换货。请记住订单号。”
2. 首轮观察到 181 次字符增量更新，首批长度为 1、2、3、4…，不是等整段完成后才开始显示。
3. 页面按 Enter 追问“刚才我的订单号是什么？”
4. 第二轮回复“刚才的订单号是 WEB20261019001。”，请求沿用首轮返回的会话 ID。
5. 桌面 1440×1000、手机 390×844 均无横向溢出；逐张查看截图，确认手机最新回复可见。
6. 点击新对话后清空当前消息并恢复欢迎页。
7. 无 pageerror。

详细结果：ch01-web-browser.json；截图见 ch01-web-desktop.png、ch01-web-mobile.png。
