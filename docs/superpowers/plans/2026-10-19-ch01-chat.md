# 电商智能客服第 1 章 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 跑通 DeepSeek 实时对话、服务端两轮上下文和售后 JSON 提取，提供 curl 演示与验证记录。

**Architecture:** FastAPI 接口调用 LangChain ChatOpenAI，统一 OpenAI Chat Completions 协议。模型层与业务层之间通过 StreamPiece 和 ModelGateway 接口隔离；内存会话仅提交完整成功的问答，结构化提取独立执行。

**Tech Stack:** Python 3.13、FastAPI 0.147.0、langchain-openai 1.7.2、langchain-core 1.6.12、pydantic-settings 2.16.0；Pydantic、Uvicorn、pytest 和 HTTPX 的兼容版本在安装时解析并锁定。

**Spec:** docs/superpowers/specs/2026-10-19-ch01-chat-design.md（用户已批准）。

## Global Constraints

- Python + FastAPI + LangChain，统一使用 OpenAI Chat Completions 协议直连上游。本次先验收 DeepSeek。
- 本章无工具调用、Agent 循环、数据库或检索。
- 按 conversation_id 保存消息，单进程运行，重启清空。
- 默认应用总预算 8192、输出预留 1024、安全余量 512。
- 内存会话配置空闲过期时间和最大会话数，默认分别为 30 分钟与 100。
- DeepSeek 显式使用 with_structured_output(PydanticSchema, method="json_mode")。
- 纯 Prompt / 数据不用镜像式单测，改用标注评估集验证；聊天页面不在本次范围。
- 所有具体库接口先经 Context7 查证；遇到协议能力或固定技术栈矛盾，停下问用户，不私自换接入方案。
- 任务完成、计划评审、code review 和 finish 各自完成时立即追记 dev-notes/ch01.md。
- 密钥只放已忽略的本地 .env，不进入代码、提交、日志或报告。

统一业务接口（以下签名是应用自定义接口，库调用实现需核对安装版本）：

```python
@dataclass(frozen=True)
class StreamPiece:
    text: str = ""
    finish_reason: str | None = None

class ModelGateway(Protocol):
    def stream(self, messages: list[BaseMessage]) -> AsyncIterator[StreamPiece]: ...
    async def extract(self, description: str) -> AfterSales: ...

def create_app(settings: Settings | None = None,
               gateway: ModelGateway | None = None) -> FastAPI: ...
def estimate_tokens(messages: list[BaseMessage]) -> int: ...
def prepare_messages(system: str, history: list[BaseMessage], user: str,
                     input_budget: int) -> list[BaseMessage]: ...

@dataclass
class Session:
    id: str
    history: list[BaseMessage]
    busy: bool
    touched_at: float

class SessionStore:
    def acquire(self, conversation_id: str | None) -> Session: ...
    def commit(self, session: Session, history: list[BaseMessage]) -> None: ...
    def release(self, session: Session) -> None: ...
```

省略号仅表示 Python Protocol / 公共签名声明，任务正文给出具体行为和实现步骤。

## Task 2：会话与历史预算

**Files:** 创建 app/context.py、app/sessions.py、tests/test_context_sessions.py。

**Consumes:** Settings、LangChain BaseMessage / SystemMessage / HumanMessage / AIMessage。

**Produces:** estimate_tokens、prepare_messages、SessionStore；ContextTooLarge、SessionNotFound、SessionBusy、CapacityExceeded 业务错误。

- [ ] 写失败测试：旧问答成对裁剪、system 与当前 user 保留、单轮过长拒绝、未知会话、同 ID 忙碌、TTL、容量、忙会话不清理、失败释放后可重试。使用可注入 clock 的 SessionStore 测 TTL，避免真实等待。

```python
def test_new_turn_is_never_silently_cut():
    with pytest.raises(ContextTooLarge):
        prepare_messages("客服", [], "很长" * 200, input_budget=50)

def test_same_session_cannot_be_acquired_twice():
    store = SessionStore(max_sessions=100, ttl_seconds=1800)
    session = store.acquire(None)
    with pytest.raises(SessionBusy):
        store.acquire(session.id)
    store.release(session)
    assert store.acquire(session.id) is session
```

- [ ] 运行 `python -m pytest tests/test_context_sessions.py -q` 观察失败。
- [ ] 实现预算：每条消息按 UTF-8 内容字节长度 + 固定消息开销计数，加入会话总开销；可用输入预算为总预算减输出减余量。历史必须保持 human / ai 成对；从最旧对开始删除，必要时抛 ContextTooLarge。提交后对 history 再按预算裁剪，内存不无限增长。
- [ ] 实现存储：单事件循环内 acquire 不含 await，原子检查并占用；monotonic 时间、随机 uuid、先回收非忙过期项、满额回收非忙最旧项，无可回收项报容量错误；release 更新活跃时间并取消忙碌。

def test_first_response_contains_session_id_and_stream(client):
    response = client.post("/chat", json={"message": "你好"})

    assert response.text.index("event: meta") < response.text.index("event: token")

- [ ] 运行 `python -m pytest tests/test_chat.py -q` 观察失败。
