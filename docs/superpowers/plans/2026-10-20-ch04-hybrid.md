# 第四章 Hybrid Retrieval Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task-by-task in the current session. Steps use checkbox syntax.

**Goal:** 真实Milvus BM25/dense混合召回、bge-reranker-v2-m3、证据拒答/引用及四策略评估。
**Architecture:** MySQL权威原文及独立hybrid索引状态；本地模型服务；有界检索流水线接入原单轮工具/SSE，生成前做证据充分性检查。
**Tech Stack:** 现有FastAPI/SQLAlchemy/MySQL/LangChain；Milvus3.0.0/PyMilvus3.0.2原生BM25、chinese analyzer、hybrid_search/RRF；BGE-M3与bge-reranker-v2-m3。
**Spec:** docs/superpowers/specs/2026-10-20-ch04-hybrid-design.md

## Global Constraints
- 固定技术，不用外部BM25或应用层RRF替换原生接口；dense/BM25各50、重排10。
- 当前会话原工作区执行，沿用用户偏好；保留第三章集合和本地分支。
- 同义词仅查询侧，本轮理解不读历史；型号/数字/否定保留；前端选择品类A。
- 后端TDD，Prompt/数据标注评估；前端Vibe Coding，不套后端流程。
- 每阶段即时追加dev-notes/ch04.md，不批量补记；独立后端评审；真实验收。
