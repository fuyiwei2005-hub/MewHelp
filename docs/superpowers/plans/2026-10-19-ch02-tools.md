# 第二章工具与持久化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 先交付数据库持久化和五工具的真实聊天链路，保存关键词漏召回基线。
**Architecture:** SQLAlchemy 异步 repository + 单轮 service + 现有 FastAPI SSE。工具闭包绑定服务器请求作用域，模型只见业务参数。
**Tech Stack:** FastAPI、SQLAlchemy 2.0、asyncmy、Docker MySQL、LangChain @tool。
**Spec:** docs/superpowers/specs/2026-10-19-ch02-tools-design.md；契约以已批准 ch03 设计中的冻结定义为准。

## Global Constraints
- 每条消息最多一次业务工具执行，最终模型 tool_choice=none；无 Agent Loop。
- MySQL 实际运行，不使用 SQLite 替代；业务账号非 root，凭证仅 .env。
- query_faq(keyword) 返回 ok/matches(question,answer,category) 或统一 error。
- 页面徽章 Vibe Coding；后端 TDD；每任务完成立即写 dev-notes/ch02.md。
- 不覆盖现有未提交工作，不删除数据库卷。
